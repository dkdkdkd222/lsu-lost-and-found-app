This is a read me for implementing the client side of the email function.
As the email function is not you integrated into claims, this creates a small react app for filling in information.
1. cd into client
2. npm i axios
3. npm start
4. Type the desired information into the web app.
5. Email should be sent to the desired user.


Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
