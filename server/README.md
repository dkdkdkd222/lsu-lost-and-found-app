This readme is for specific intructions implementing the server side of the email function in the LSU-lost-and-found-app.
1. From the root project cd into server/
2. then install resnd @react-email/components react-dom express cors resend dotenv
3. Once installed use the add the resend key into the app.js
4. run npm nodemon app.js
5. You have done everything you need to do to get the server running
